# motion.md v0.2.0 — Align with DESIGN.md / 对齐 DESIGN.md

Google Labs' `DESIGN.md` gained a `## Motion & Micro-interaction` section and `motion` tokens on 2026-11-17, along with external `@` references, grouped tokens, interleaved YAML blocks, and `omitted`. v0.2 redraws the boundary: `DESIGN.md` owns the timing vocabulary, `MOTION.md` owns behavior and references that vocabulary instead of restating it.

2026-11-17，Google Labs 的 `DESIGN.md` 加入了 `## Motion & Micro-interaction` 章节与 `motion` token，同时正式定义了 `@` 外部引用、分组 token、穿插 YAML 块和 `omitted`。v0.2 据此重划边界：时序词汇归 `DESIGN.md`，`MOTION.md` 只负责行为，并引用而不是复制这些词汇。

## Added / 新增

- `design`: bind a sibling `DESIGN.md`. / 绑定同目录的 `DESIGN.md`。
- `timing: "{motion.<token>}"` on `defaults` and tracks, with exact CSS easing mapping; `timing` plus literal `durationMs`/`curve` is an error. / 在 `defaults` 和轨道上引用 motion token，CSS easing 精确映射；与字面时序字段同时出现即报错。
- Motion IR records resolved values, synthesized `origin: "design"` curves, and the `DESIGN.md` hash. / Motion IR 落解析后的数值、来自 design 的曲线和 `DESIGN.md` hash。
- `prefer-design-token` info when a literal equals a token. / 字面值等于 token 时给出提示。
- Interleaved ` ```yaml ` blocks; duplicate top-level keys are errors. / 穿插 YAML 块；顶层键重复即错误。
- `omitted` for prose sections, with `unknown-omission` and `redundant-omission`. / 声明省略的正文章节。
- External `` `@path#fragment` `` references with `DESIGN.md` severities. / 外部引用，严重级别与 `DESIGN.md` 一致。
- CI runs `npm run check` on pushes to `main` and on pull requests. / CI 在推送到 `main` 和每个 PR 上运行 `npm run check`。

## Changed / 变更

- `version` is `"0.2"`; Motion IR `irVersion` is `"0.2"`. v0.1 documents are rejected. / 版本为 `"0.2"`，不再接受 v0.1 文档。
- `missing-frontmatter` is renamed `missing-machine-data`. / 规则改名。
- Headings and references inside fenced code are no longer read as structure. / 代码块内的标题和引用不再被当作结构。

## Not adopted / 未跟进

- Grouped tokens: `MOTION.md` maps hold named entities, not tokens; references to grouped `DESIGN.md` motion tokens work through dot paths. / 分组 token：我们的映射是命名实体而非 token；引用分组 motion token 可用点路径。
- Voice & Content Strategy: outside motion. / 与动效无关。

## Migration / 迁移

1. Change `version: "0.1"` to `version: "0.2"`. / 把版本改成 `"0.2"`。
2. If the project has a `DESIGN.md` with `motion` tokens, add `design: DESIGN.md` and replace each track's `durationMs` + `curve` that match a token with `timing: "{motion.<token>}"`. `motionmd lint` lists candidates as `prefer-design-token`; it only suggests tokens with a zero delay, because a token delay is added to `startMs`. For a delayed token, lower the track's `startMs` by the delay when switching. / 若项目的 `DESIGN.md` 有 motion token，加上 `design`，并按 `prefer-design-token` 提示把对应字面值换成 `timing` 引用；该提示只针对 delay 为 0 的 token，因为 token delay 会叠加到 `startMs`，换用带 delay 的 token 时要相应减小 `startMs`。
3. Rename any tooling that matches `missing-frontmatter`. / 更新匹配旧规则名的工具。
